
# Mouse and Keyboard Control Using Gesture Recognition

## Project Overview

This project aims to develop a real-time computer vision-based
system that enables users to control mouse and keyboard
functionalities through hand gestures captured using a webcam.

## Objectives

- Real-time hand detection and tracking.
- Hand gesture recognition.
- Virtual mouse control.
- Virtual keyboard implementation.
- Performance evaluation under different conditions.

## Technologies Used

- Python
- OpenCV
- MediaPipe
- NumPy
- Scikit-learn
- PyAutoGUI
- Tkinter

## Project Structure

- data/: Dataset storage
- src/: Main implementation
- experiments/: Experimental scripts
- results/: Graphs, tables and evaluation results

## Current Status

Project development and implementation in progress.
